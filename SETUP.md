# Set up this GitHub profile README

1. Create a public repository named **`OMDATTA`** (the repository name must match your GitHub username exactly).
2. Copy `README.md` and the entire `assets/` folder into the repository root.
3. Commit and push. GitHub will render the README on `https://github.com/OMDATTA`.
4. Edit project descriptions and skill badges as your work evolves. Keep technologies under “use or am actively learning” honest to your current experience.

The images in `assets/` are local SVGs. Keep their relative paths intact so the banner and dividers render correctly.
